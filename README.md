# MERIDIAN — 글로벌 마켓 터미널

세계 주요 지수·비트코인·금과 최대 9개 관심 종목을 모니터링하는 한국어 대시보드입니다. 차트와 상단 시세 카드를 직접 렌더링하며, 외부 iframe이나 차트 위젯을 사용하지 않습니다.

## 실행

```sh
npm start
```

Node.js와 Python 3가 설치된 환경에서 실행하고 `http://localhost:4173`에 접속합니다. npm 패키지 설치나 빌드는 필요하지 않습니다. Python만 있다면 `python3 -m http.server 4173 --directory dist`로 실행할 수 있습니다.

## 가격 데이터 연결

1. [Twelve Data](https://twelvedata.com/) 계정을 만들고 API 키를 발급합니다.
2. 앱 오른쪽 위 **데이터 연결**에서 키를 입력합니다. 대화나 GitHub에 키를 올리지 마세요.
3. 분당 요청 수를 실제 요금제 한도 이하로 설정하고 자동 갱신 주기를 선택합니다.
4. **연결하고 불러오기**를 누르면 차트와 상단 시세가 순서대로 표시됩니다.

API 키는 현재 탭의 메모리에만 보관합니다. 소스, localStorage, sessionStorage에 저장하지 않으며 새로고침 후 다시 입력해야 합니다. 개인 브라우저에서 Twelve Data로 직접 요청하는 방식이므로 브라우저 개발자 도구에서는 본인의 요청을 확인할 수 있습니다. 키는 Authorization 헤더로 전달하며 URL에 넣지 않습니다. 공용 키를 숨겨 여러 사용자에게 데이터를 제공하려면 별도 서버와 해당 배포·재배포 라이선스가 필요합니다.

**API 키 없이는 가격이 표시되지 않습니다.** 무료 요금제로 전 세계 주식·지수·원자재가 모두 제공되는 것은 아닙니다. 거래소별 실시간·지연 여부, 데이터 제공 권한과 일간·분당 한도는 가입 요금제에 따릅니다. 권한 부족과 지원되지 않는 종목은 해당 카드에 표시합니다. 초기 화면에는 최대 19개 요청(차트 9개와 시세 10개)이 필요합니다. 8회/분 설정에서는 표시까지 수 분이 걸릴 수 있습니다. 요청을 순차 처리하고 429 응답 후 대기하며, 시간 이력은 5분, quote는 1분 동안 메모리에 캐시합니다.

상단 시세는 `/quote`의 최신 가격·전일 대비 변동·기준 시각을 사용합니다. 지수는 `GSPC`, `IXIC`, `DJI`, `KS11`, `N225`, `HSI`, `GDAXI`, `FTSE`를 Index 유형으로 조회합니다. 공급자의 지원·계정 권한에 따라 제공되지 않을 수 있습니다. 비트코인은 BTC/USD 집계 시세, 금은 XAU/USD 현물(USD/트로이온스)입니다. 종목 차트는 `/time_series`의 180개 OHLC 봉을 사용하며 일봉·주봉·월봉마다 실제 해당 주기 이력을 요청합니다. 차트 상단 가격은 마지막 봉의 종가, 변동률은 이전 봉의 종가 대비입니다. 기본 자동 갱신은 5분이며 숨겨진 탭에서는 새 요청을 만들지 않습니다.

## 기능

- 직접 구현한 SVG 캔들·선 차트, 거래량, OHLC 툴팁, 십자선
- 휠 또는 +/- 키로 확대·축소, 드래그 또는 좌우 키로 과거 탐색
- 더블클릭으로 기본 보기, Home 키로 최근 구간 이동
- 그룹 생성·이름 변경·삭제, 종목 추가·제거, 그룹별 9개 제한과 중복 방지
- 일봉·주봉·월봉, 캔들·선 전환, 3열·2열 배치와 모바일 화면
- 미국·한국·아시아·유럽 등의 기본 종목 검색과 거래소:티커 직접 입력
- 기존 관심 종목 저장 형식 유지 및 Twelve Data 거래소 코드 변환
- 브라우저에 그룹·차트 설정 저장, 다른 탭의 변경 반영

검색 목록은 미리 정의한 종목 목록이며 글로벌 심볼 검색 API가 아닙니다. 목록 밖 종목은 Twelve Data의 심볼과 거래소를 확인해 직접 추가합니다. 그룹은 계정·기기 간 동기화되지 않습니다. 가격을 임의로 생성하거나 모의 가격으로 대체하지 않습니다.

## 배포

main은 소스, gh-pages는 dist/ 내용과 .nojekyll을 루트에 둔 정적 배포 브랜치입니다. GitHub 저장소 Settings → Pages에서 **Deploy from a branch → gh-pages → /(root)**를 설정합니다. 배포 주소는 https://pokposu124.github.io/Meridian/ 입니다.

## 검증

```sh
npm test
npm run check
```

상태 보존·심볼 검증·9개 제한, OHLC 정규화와 날짜 검증, 표시 구간, null 시세 처리, API 인증 헤더·캐시·요청 제한·취소·오류 처리를 검증합니다. API 테스트는 모의 응답을 사용하며 실제 계정의 해외 시장 접근 권한이나 브라우저 CORS 동작을 보장하지 않습니다.
