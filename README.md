# MERIDIAN — 글로벌 마켓 터미널

세계 주요 지수·비트코인·금과 최대 9개 관심 종목을 모니터링하는 한국어 대시보드입니다. 차트와 상단 시세 카드를 직접 렌더링하며, 외부 iframe이나 차트 위젯을 사용하지 않습니다.

## 실행

```sh
npm start
```

Node.js와 Python 3가 설치된 환경에서 실행하고 `http://localhost:4173`에 접속합니다. npm 패키지 설치나 빌드는 필요하지 않습니다. Python만 있다면 `python3 -m http.server 4173 --directory dist`로 실행할 수 있습니다.

## 기본 데이터: API 키 없는 공개 지연 시세

사이트를 열면 Yahoo Finance 공개 chart 응답을 정기 수집한 데이터를 자동으로 읽습니다. 회원가입이나 Twelve Data API 키가 필요하지 않습니다. 미국·한국·일본·홍콩·대만·인도·유럽 등 기본 종목과 주요 지수, 비트코인·이더리움, 금 선물을 수집합니다. 세계시장 보기용 주요 지수 55개와 대표 종목 263개를 선정했습니다. 기존 상단 별칭과 암호화폐·금 항목을 합쳐 총 330개 수집 항목을 관리합니다. 제공처에서 조회되지 않는 항목은 미지원으로 표시하므로 실제 가격이 확보된 수는 화면에서 확인해야 합니다. 전 세계 전 종목 목록은 아닙니다.

GitHub Actions의 Refresh public market data 작업이 매시 17분과 47분(UTC)에 실행되도록 설정했습니다. 실행 지연, 공급자 지연, GitHub CDN 캐시로 인해 실제 갱신은 더 늦어질 수 있습니다. 화면은 기본 5분마다 저장된 데이터를 확인합니다. 시세 기준 시각과 수집 시각은 서로 다르므로 둘을 확인하세요. 비공식 공개 연결은 공급자 변경·호출 제한·지원 중단으로 실패할 수 있습니다.

수집 목록은 data/universe.json에 있습니다. id는 앱에서 사용하는 거래소:티커, symbol은 Yahoo Finance 심볼입니다. 새 종목을 목록에 추가해 main에 저장하면 수집 작업이 다시 실행됩니다. 목록에 없는 종목은 자동 가격을 만들지 않고 미지원 안내를 표시합니다. 기존 OANDA:XAUUSD 금 현물 심볼을 선물 가격으로 대체하지 않습니다.

공개 모드 상단 금은 **GC=F(COMEX 금 선물)**이며 현물 XAU/USD와 다릅니다. 비트코인은 BTC-USD 집계 시세입니다. 종목 차트는 일별 OHLC를 바탕으로 거래소 현지 거래일의 주·월별 첫 시가·고가·저가·마지막 종가·거래량 합계를 계산합니다. 일봉·주봉은 최대 180개, 월봉은 약 10년치입니다. 차트 가격은 마지막 봉 종가이고 상단 시세는 공급자가 보고한 최신 가격입니다.

수집된 파일은 gh-pages의 data/에 저장합니다. 클라이언트는 raw.githubusercontent.com의 JSON을 읽으므로 이후 정기 데이터 갱신에 Pages 재빌드가 필요하지 않습니다. Github 자동 발급 GITHUB_TOKEN을 수집 워크플로에 사용하며 별도 제공업체 키는 사용하지 않습니다. 모든 원본 가격이 실패한 첫 수집은 빈 값을 배포하지 않고 작업을 실패시킵니다. 갱신 실패 시 이전 유효 데이터와 기준 시각을 보존하고 stale로 표시하며, 2시간 이상 수집되지 않은 값도 오래된 데이터로 표시합니다.

GitHub Actions에서 workflow_dispatch로 수집을 수동 실행할 수도 있습니다. 공개 저장소의 예약 워크플로는 장기간 저장소 활동이 없으면 GitHub 정책에 따라 비활성화될 수 있습니다.

## 선택 데이터: Twelve Data

데이터 연결에서 Twelve Data를 선택하면 기존 개인 API 방식도 사용할 수 있습니다. [Twelve Data](https://twelvedata.com/)에서 발급한 API 키를 앱에 직접 입력하고 실제 요금제 이하의 분당 요청 수를 설정하세요. 가입 요금제에 따라 해외 시장·지수·금 현물의 접근 권한과 지연이 다릅니다. 무료 요금제로 모든 시장이 제공되지는 않습니다.

키는 현재 탭 메모리에만 보관합니다. 소스, localStorage, sessionStorage에 저장하지 않고 새로고침 후 지웁니다. 키는 Twelve Data에 Authorization 헤더로 전송하며 공개 URL에 넣지 않습니다. 공용 키를 여러 방문자에게 제공하려면 별도 서버 및 해당 데이터 이용 권한이 필요합니다. 공개 시세로 전환할 때는 입력했던 키를 메모리에서 지웁니다.

## 세계시장 전체 보기

상단 또는 사이드바의 **세계시장 전체 보기**를 열면 미국·유럽·한국·아시아·캐나다와 중남미·오세아니아·중동·아프리카의 주요 지수와 대표 종목을 표로 비교할 수 있습니다. 지역·지수/종목 유형·국가명/기업명/티커 검색으로 필터링합니다. 지수는 포인트(pt), 주식은 각 거래소의 가격 통화를 사용합니다.

각 행에 가격, 변동률, 시세 기준 시각, 이전 수집 여부를 표시하며, 정상·이전 수집·미지원 수를 합산합니다. 차트 버튼으로 네이티브 차트를 열고 +로 현재 관심 그룹에 추가합니다. 그룹당 최대 9개 제한과 기존 사용자 그룹은 유지됩니다. 수집 목록 메타데이터가 종목 검색에 자동 반영되어 기존의 55개 기본 종목 목록에 묶이지 않습니다.

전체 시세 표는 수집 manifest에 저장된 quote를 한 번에 읽습니다. 표를 열 때 수백 개 가격 이력 파일을 따로 다운로드하지 않습니다. 차트를 열 때만 해당 종목 이력을 읽습니다. 전체 이력은 하루 한 번 갱신하고, 당일 후속 수집은 최근 5일 데이터를 합쳐 오래된 주·월 이력을 보존합니다. 호출 제한 시 중단하며, 다음 수집에서는 미확보 항목과 다른 국가를 우선 순환해 갱신합니다.

## 기능

- 직접 구현한 SVG 캔들·선 차트, 거래량, OHLC 툴팁, 십자선
- 휠 또는 +/- 키로 확대·축소, 드래그 또는 좌우 키로 과거 탐색
- 더블클릭으로 기본 보기, Home 키로 최근 구간 이동
- 그룹 생성·이름 변경·삭제, 종목 추가·제거, 그룹별 9개 제한과 중복 방지
- 일봉·주봉·월봉, 캔들·선 전환, 3열·2열 배치와 모바일 화면
- 미국·한국·아시아·유럽 등의 기본 종목 검색과 거래소:티커 직접 입력
- 기존 관심 종목 저장 형식 유지 및 Twelve Data 거래소 코드 변환
- 브라우저에 그룹·차트 설정 저장, 다른 탭의 변경 반영

검색 목록은 미리 정의한 종목 목록이며 글로벌 심볼 검색 API가 아닙니다. 공개 모드에서 목록 밖 종목을 사용하려면 data/universe.json에도 추가해야 합니다. Twelve Data 모드에서는 해당 제공업체의 심볼과 거래소를 사용합니다. 그룹은 계정·기기 간 동기화되지 않습니다. 가격을 임의로 생성하거나 모의 가격으로 대체하지 않습니다.

## 배포

main은 소스, gh-pages는 dist/ 내용과 .nojekyll을 루트에 둔 정적 배포 브랜치입니다. GitHub 저장소 Settings → Pages에서 **Deploy from a branch → gh-pages → /(root)**를 설정합니다. 배포 주소는 https://pokposu124.github.io/Meridian/ 입니다.

## 검증

```sh
npm test
npm run check
```

상태 보존·심볼 검증·9개 제한, OHLC 정규화와 날짜 검증, 표시 구간, null 시세 처리, API 인증 헤더·캐시·요청 제한·취소·오류 처리를 검증합니다. 자동 테스트는 46개이며 API 테스트에는 모의 응답을 사용합니다. 별도로 GitHub에서 실제 수집된 미국·한국 가격의 일·주·월 이력과 금 선물 quote를 클라이언트로 검증했습니다. 브라우저 화면 동작과 Twelve Data 실계정 권한은 별도 확인이 필요합니다.
