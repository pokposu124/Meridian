# MERIDIAN — 글로벌 마켓 터미널

세계 주요 지수와 비트코인·금 현물 시세, 그룹별 최대 9개 종목 차트를 보여주는 한국어 대시보드입니다.

## 사용

정적 웹 서버로 `dist/`를 제공합니다. 빌드나 API 키가 필요하지 않습니다. 외부 네트워크를 사용할 수 있는 브라우저에서 열어야 시세가 표시됩니다.

```sh
npm start
```

Node.js와 Python 3가 설치된 환경에서 실행한 다음 `http://localhost:4173`에 접속하세요. npm 패키지 설치는 필요하지 않습니다. Python만 있다면 `python3 -m http.server 4173 --directory dist`로도 실행할 수 있습니다. GitHub Pages 등의 정적 호스팅에서는 `dist/`의 파일들을 배포 디렉터리로 사용합니다.

- 그룹 생성·이름 변경·삭제, 종목 추가·제거
- 그룹별 9개 제한, 중복 종목 방지
- 일봉·주봉·월봉, 캔들·선 전환
- 3열·2열 배치, 반응형 모바일 화면, 차트 확대
- 미국·한국·일본·중국 홍콩·대만·인도·유럽 등 추천 검색 및 `거래소:티커` 직접 입력
- 그룹·설정의 브라우저 로컬 저장 및 다른 탭 변경 반영

시세와 차트는 TradingView 공식 임베드를 통해 조회합니다. 금은 OANDA:XAUUSD 현물, 비트코인은 BITSTAMP:BTCUSD입니다. 거래소별 실시간 여부, 지연 및 외부 위젯 지원 여부가 다릅니다. 종목 검색 목록은 미리 정의한 목록이며 전체 글로벌 종목 검색 API는 아닙니다. 목록 밖 종목은 직접 심볼을 입력합니다. 위젯 불러오기 실패 시 안내와 원본 차트 링크를 제공합니다. 임의 시세나 모의 가격을 표시하지 않습니다.

개인 그룹은 해당 브라우저에 저장되며 서버 계정·기기 간 동기화는 제공하지 않습니다.
